# Baton Spec Kit extension

`extension.yml` registers mandatory, unconditional receive and handoff
hooks for specify, clarify, plan, tasks, analyze, implement and converge.
The hook commands call the bundled Baton CLI. Install into a Spec Kit
project through `specify extension add --dev <path-to-this-directory>`;
the maintainer's `baton sync` materializes the result. No core Spec Kit
prompt is edited.
