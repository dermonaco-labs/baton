# Support

For usage questions, consult the [Baton manual](docs/README.md) and
[troubleshooting guide](docs/08-troubleshooting.md) first. Open a
GitHub issue using the [issue templates](.github/ISSUE_TEMPLATE/) for
reproducible bugs, feature requests, and configuration issues. For usage
questions, describe what you tried and the relevant diagnostic output
without including secrets.

Do not post credentials, personal data, or private security findings. Report
vulnerabilities through [private vulnerability reporting](SECURITY.md).
