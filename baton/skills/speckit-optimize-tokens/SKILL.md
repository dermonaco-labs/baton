# Report-Only Governance Token Estimates

Run `node .baton/bin/baton.mjs --json context optimize tokens`.
Use `.baton/vendor/optimize/commands/speckit.optimize.tokens.md` only as
reporting reference. Label estimates as character-based approximations, not
provider billing. Report overhead and proposed wording improvements without
applying them or persisting any tracking file.

Reject apply-like requests. Constitution amendments belong to
`/speckit-constitution`, never this wrapper. Preserve all mandatory gates,
scanner rules, approvals, instruction markers and governance meaning.
Never modify constitution, agent instructions, persistent memory, handoffs,
`.baton/phases.yml` or built-in enforcement to meet a budget.
Preserve diagnostics and failure status.
